# 郭瀞婷 Tina Kuo — 作品目錄 Works Catalogue

這份檔案是本站作品頁的唯一輸入清單：`content/works/zh/*.md`、`content/works/en/*.md`
與 `assets/source-images/` 的封面都由此延伸。內容依出版社與通路頁面於 2026-11-17
查核後整理；`tagline_zh` 為出版社文案原文，`summary_zh` 與 `summary_en` 為本目錄自行
改寫的摘要。

版次（`editions`）不另立作品條目：改版、紀念版、二版、簡體版、電子書與有聲書都記在
所屬作品的 `editions` 之下。

## 欄位說明

- `slug` — 中文路由代稱；已在站上的作品等於 `content/works/zh/` 的檔名（去掉 `.md`）。
- `slug_en` — 英文路由代稱，沿用 `content/works/en/*.md` 的 `slug:`。
- `title_zh` / `title_en` — 作品名；`title_en_status` 為 `verified-existing`（站上既有）、`official`（出版社官方英文名）或 `proposed`（本目錄暫譯）。
- `authors` / `illustrators` / `contributors` — 作者、繪者、合著者或協力者，依出版社排序。
- `role` — 郭瀞婷在本書的角色：`文`、`文·圖`、`合著`、`故事構成`。
- `publisher` / `first_published` / `date_precision` — 首次出版出版社與日期；`date_precision` 為 `day`、`month` 或 `year`。
- `isbn` / `binding_pages` — 現行主要版本的 ISBN 與裝訂規格；未取得者為 `""`。
- `age_band` — 出版社標示的適讀年齡層。
- `kind` — `繪本`、`橋梁書`、`小說`、`選集`、`音樂劇`。
- `collection` — 對應 `content/collections.ts` 的 `CollectionId`。
- `series` — 所屬系列；單行本為 `""`。
- `tagline_zh` — 出版社行銷文案原文（不改寫）。
- `summary_zh` / `summary_en` — 2–3 句摘要與其英文翻譯。
- `awards` — 出版社頁面載明的獎項與推薦紀錄。
- `status` — `在版`（仍可經通路或電子書取得，含「無庫存，購買後進貨」）或 `絕版`（通路價格區顯示「已售完，無法購買」，且無電子書或其他版本在售）。判定只看價格區供貨狀態與電子書通路是否上架；頁面側欄的「可訂購時通知我」是願望清單連結，不能當作有貨。
- `in_site` — `content/works/zh/<slug>.md` 是否已存在。
- `cover_source_url` / `cover_file` — 封面的正當出處網址與 `assets/source-images/` 內的目的檔；實際下載路徑見〈封面取得方式〉。
- `editions` — 其他版本，每筆含 `label`、`date`、`publisher`、`isbn`、`note`。
- `sources` — 本次查核所依據的頁面。
- `notes` — 其他需註記的事實。

## 封面取得方式

封面檔不是從 `books.com.tw` 直接下載的。本機的 `curl` 對 `www.books.com.tw/img/...`
一律收到 Cloudflare 的 403 挑戰頁（1781 bytes 的 HTML，`file` 會回 `text/html`）；
同 IP 的無頭 Chromium 開得了商品頁，但抓圖仍然被擋，重試與加 `Referer`／cookie 都無效。

實際做法是把已知的圖檔網址交給公開影像代理 `wsrv.nl`，由代理端連線取回：

```sh
curl -sL -o assets/source-images/book-cover-胡阿布偵探事件簿.jpg \
  "https://wsrv.nl/?url=www.books.com.tw/img/001/104/75/0011047555.jpg"
```

沒有加 `w=`、`h=`、`output=` 參數，拿回的是代理端所提供的原尺寸 JPEG（1000×1389 等），
不是縮圖。但 `wsrv.nl` 會解碼後重新輸出、也可能回傳快取副本，所以**不能保證與出版社原檔
逐 byte 相同**；`cover_source_url` 記的是圖檔的正當出處（`books.com.tw` 或
`cdn.readmoo.com`），不是代理網址。下載後以 `file -b --mime-type` 與 `sharp` 檢查是否為
JPEG 且寬度 ≥ 200 px——這是目前唯一的品質關卡，沒有逐張人工目視。

`小兒子報告！沙發有黑洞` 用的是站上既有主視覺橫式圖檔、`記憶邊境` 沿用站上既有平面圖檔，
兩者都沒有對應的原始下載網址，故 `cover_source_url` 為 `""`。
